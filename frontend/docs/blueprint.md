# **App Name**: FeatureFlow Admin

## Core Features:

- User Authentication & Authorization: Secure user registration, login, JWT token management, and protected routing for administrative access.
- Dashboard Analytics Overview: Display key metrics like total projects, flags, and environments with visual charts for flag status and rollout percentages.
- Project & Environment Management: CRUD operations for projects, view environments, generate and copy API keys, and access project-specific configurations.
- Feature Flag Lifecycle Management: Create, view, enable/disable feature flags per environment, including a dedicated editor for advanced rollout rules.
- Audit Trail Monitoring: Display a comprehensive log of all actions taken within the system, including user, timestamp, and state changes, with pagination.
- Flag Simulation & Testing Tool: A tool to simulate feature flag evaluations by providing user attributes, showing how flags would be returned based on configured rules.
- Dynamic UI Interactivity & Enhancements: Implement search and filter functionalities for flags, instant toggles, toast notifications, loading skeletons, and responsive design.

## Style Guidelines:

- Color scheme: Dark theme suitable for a professional developer tool. Background color: A deep desaturated blue-gray (#191C27) for a sophisticated base. Primary color: A rich, professional blue (#7E8ECD) for interactive elements and key information, evoking precision and control. Accent color: A vibrant cyan-blue (#2699D9) for highlights and calls to action, providing clear visual contrast.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly readable characteristics, fitting a data-rich dashboard.
- Utilize Lucide Icons to ensure a consistent, clean, and minimalist icon set across the application.
- Implement card-based layouts for data presentation, a persistent sidebar navigation, and a responsive grid system for dashboard elements. Emphasis on clean separation of content and clear hierarchy, similar to leading SaaS dashboards.
- Incorporate smooth and subtle transitions for state changes, interactive elements like toggles and buttons, and navigation, to enhance user experience without distraction.
